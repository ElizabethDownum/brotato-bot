# Brotato Bot Mod Implementation Plan (plan 1 of 3)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A fork of BOTato, renamed `Ellie-BrotatoBot`, that loads on Brotato 1.1.15.4, plays a run on profile 1 from a plan file, records everything to JSONL, exports state, asks the sidecar for decisions through request/response files, checkpoints on the target unlock, and halts on anything that looks like Ellie's own play.

**Architecture:** GDScript mod loaded by the Godot Mod Loader shipped in the game. Game-dependent code lives in `extensions/` (script extensions of game files) exactly as BOTato does; new pure-logic code lives in `core/` as `Reference` scripts with explicit path parameters so a stock Godot 3.6 headless binary can unit test them without the game. Game integration is verified by launching the game and reading the mod loader log plus one attended run.

**Tech Stack:** GDScript (Godot 3.x syntax, the game is a custom 3.7 dev build), Godot 3.6-stable win64 binary for headless tests, PowerShell helper scripts, git.

## Review Focus

1. `plan.json` missing or malformed while the bot is enabled: the bot must stay disabled and the overlay must say why, never crash the shop. (Task 3 test `test_plan_file_invalid_json_returns_null`.)
2. A response file that arrives after the timeout, or for a different request id: it must be ignored and deleted, not applied to the next decision. (Task 8 test `test_stale_response_is_ignored`.)
3. Ellie presses a movement key while the bot plays on profile 1: halt within one frame, log the event, show HALTED. (Task 5 test `test_human_input_detects_move_actions`.)
4. Wave 20 cleared with the shop opening afterwards: the completion gate must fire once and the shop must not run auto-shop again. (Task 7 attended check.)
5. Game paused for a decision while `pause_on_focus_lost` is also true and the window loses focus: resuming must not double-unpause into a wave the bot thinks is paused. (Task 8 attended check: alt-tab during a decision.)
