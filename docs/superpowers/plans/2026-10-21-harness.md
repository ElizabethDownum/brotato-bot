# Brotato Bot Harness and Sidecar Implementation Plan (plan 2 of 3)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Python package `brotato_bot` that builds the ground-truth dataset and unlock graph from the local game, caches guide knowledge, prepares and collects runs into markdown reports, and runs the sidecar that answers the mod's decision requests through the Claude Code CLI with a strict schema, logging every decision and its outcome.

**Architecture:** One `uv`-managed package with an argparse CLI (`python -m brotato_bot <command>`). Spud Coach's parser and builders are folded in under `brotato_bot/dataset/spud/`. The sidecar is a polling loop over the mod's `requests/` folder; it shells out to `claude -p` and never imports an API client. All file writes are atomic (tmp + rename). Pure functions take paths and dictionaries so pytest covers them without the game.

**Tech Stack:** Python 3.12, `uv`, `pytest`, `pydantic` (Spud Coach's schemas use it), `ruff`. Stdlib `urllib` for the wiki API, `subprocess` for the CLI.

**Spec:** `C:\Users\eliza\Desktop\ClaudeFiles\brotato-bot\docs\superpowers\specs\2026-10-21-brotato-bot-design.md`

## Global Constraints

- Python `>=3.12`; dependencies limited to `pydantic`; dev `pytest`, `ruff`.
- Paths (single source in `brotato_bot/paths.py`): game dir `D:\SteamLibrary\steamapps\common\Brotato`; save dir `%APPDATA%\Brotato\<steam64 id>`; mod user dir `%APPDATA%\Brotato\brotato-bot` with `plan.json`, `config.json`, `runs/`, `state/`, `requests/`, `responses/`; project dirs `data/` (gitignored), `knowledge/cache/`, `runs/`, `decisions/`, `proposals/`, `advice/`, `learnings/`. Every path is overridable by an env var `BROTATO_BOT_<NAME>` for tests.
- Game version `1.1.15.4`. Bot profile id `1`. Models: Haiku `claude-haiku-5-5`, Sonnet `claude-sonnet-5-5`.
- Decision response schema (the contract): `{action: "buy"|"reroll"|"lock"|"skip"|"pick"|"revise_plan", option_index?: int >= 0, plan_patch?: object, confidence: number 0..1, rationale: string <= 300 chars, tags: string[]}`; `option_index` required for `buy`, `lock`, `pick`; `plan_patch` required for `revise_plan`; no additional properties.
- Timeouts (config, tunable): shop/levelup `45000` ms, checkpoint `120000` ms.
- Validation ladder on an invalid answer: retry once with the error appended; then a separate repair call given prior prompt + malformed output + error; then rule fallback (`None` returned, logged as `fallback`).
- No API keys; the only model access is the `claude` CLI on PATH (`claude --version` must print a version). Verified flags on 2.1.307: `-p`, `--model`, `--output-format json`, `--json-schema`, `--system-prompt-file`.
- Nothing derived from the pck is committed (`data/` is gitignored). Spud Coach's MIT notice goes in `LICENSE` under Third-party and its upstream commit in `learnings/upstream.md`.
- Commit messages end with `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.

## Review Focus

1. The CLI prints valid JSON whose `structured_output` (or `result`) is a string containing JSON rather than an object: the parser must handle both shapes. (Task 8 test `test_parse_cli_output_accepts_string_or_object`.)
2. A request file appears while the sidecar is mid-call for another: it must be queued, not lost, and answered in order. (Task 9 test `test_requests_processed_in_order`.)
3. The mod's JSONL is truncated mid-line by a crash: `collect` must still render the report from the complete lines and mark the run `incomplete`. (Task 5 test `test_collect_tolerates_truncated_last_line`.)
4. Wiki page fetch fails or the page moved: `knowledge fetch` must keep the previous cached copy and report the failure, never leave an empty file. (Task 4 test `test_fetch_failure_keeps_old_cache`.)
5. Save file lists a challenge hash that no `.tres` produces (DLC disabled or newer game): `unlock-state` must list it under `unknown` rather than crash. (Task 3 test `test_unknown_hashes_are_reported`.)
